# Статусы разработки

Project Iris использует короткие статусы, чтобы показать надежность и готовность
функции или модуля.

## Значения

- Запланировано: идея зафиксирована, но проектирование еще не началось.
- Проектирование: уточняются требования и архитектура.
- Прототип: существует ранняя реализация.
- Тестирование: реализация проверяется в реальных сценариях.
- Готово: возможность подходит для регулярного использования.
