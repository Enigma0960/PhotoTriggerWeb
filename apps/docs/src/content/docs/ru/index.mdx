# Документация Project Iris

Project Iris — открытая аппаратная платформа для триггера камеры и
автоматизации съемки.

## Статус документации

Документация пишется параллельно с разработкой аппаратной части и прошивки.
Русская и английская версии страниц хранятся отдельно, поэтому они могут
отличаться по детализации и степени готовности.

## Разделы

- Аппаратная часть
- Прошивка
- Интерфейсы камеры
- Датчики
- Механика
- Сборка
- Разработка
