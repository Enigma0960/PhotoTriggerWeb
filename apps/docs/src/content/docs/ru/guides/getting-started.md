# Быстрый старт

Этот раздел собирает первые ориентиры для читателя, который открывает
документацию Project Iris впервые.

## Текущий охват

- Начните со страниц аппаратных триггеров.
- Проверяйте статус разработки перед сборкой модуля.
- Если страница на выбранном языке еще не готова, Starlight покажет fallback из
  английской версии.
