# Триггер молнии

Триггер молнии обнаруживает быстрое изменение уровня освещенности и формирует
событие спуска камеры.

## Статус разработки

Проектирование.

## Назначение

Подсистема предназначена для автоматической съемки молний и других коротких
ярких световых событий.

## Архитектура

Подробная аппаратная архитектура будет добавлена после стабилизации схемы.
На этом этапе важно зафиксировать требования к датчику освещенности, задержке
обработки и способу электрической развязки камеры.

## Настройка

Финальная реализация должна поддерживать настройку чувствительности срабатывания
и временных параметров импульса.
