# Getting Started

This guide collects the first checkpoints for readers who are opening the
Project Iris documentation for the first time.

## Current scope

- Review the hardware trigger pages.
- Check the development status before building a module.
- Prefer the page in your language when it exists; otherwise Starlight will use
  the English fallback content.
