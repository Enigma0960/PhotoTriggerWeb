# Development Statuses

Project Iris uses short status labels to show how reliable a feature or module is.

## Values

- Planned: the idea is tracked, but design work has not started.
- Design: requirements and architecture are being shaped.
- Prototype: an early implementation exists.
- Testing: the implementation is being checked against real use.
- Ready: the feature is suitable for regular use.
