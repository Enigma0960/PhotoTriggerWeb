# Lightning Trigger

The Lightning Trigger detects rapid changes in ambient light
and generates a camera trigger event.

## Development status

Design.

## Purpose

The subsystem is intended for automatic photography of lightning
and other short-duration high-intensity light events.

## Architecture

Detailed hardware architecture will be added as the circuit
design is finalized.

## Configuration

The final implementation is expected to provide configurable
trigger sensitivity and timing parameters.
